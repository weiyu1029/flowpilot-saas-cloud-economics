# ADR 003 — Include an Explainable, No-Key Insights Copilot

**Status:** Accepted

## Decision
Provide a rule-based natural-language answer layer for common portfolio questions.

## Rationale
A public app should work without secrets, variable model output, or external cost. Answers remain tied to displayed metrics.

## Future option
Add grounded Claude, OpenAI, or Amazon Bedrock retrieval over approved KPI and recommendation documents, with evaluation, citations, authorization, and human review.
