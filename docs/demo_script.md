# 6-Minute Demo Script

## 0:00–0:40 — Problem
Introduce FlowPilot, the stakeholder problem, and why cost without product/customer context is incomplete.

## 0:40–1:30 — Executive Overview
Show MRR, cost, margin, risk accounts, budget, and revenue-vs-cost trends. Explain that synthetic data is deterministic and reproducible.

## 1:30–2:30 — Feature Economics
Use the quadrant to distinguish Efficient Winners, Scale Carefully, Monitor, and Optimization Priority. Discuss AI Assistant, Dashboard Reporting, Advanced Analytics, and File Storage.

## 2:30–3:20 — Customer Profitability
Filter to Enterprise and show accounts above the 25% cost-to-revenue threshold. Explain that risk is a prioritization signal, not an automated commercial decision.

## 3:20–4:10 — AWS FinOps & Reliability
Show service/environment cost, budget trend, incidents, and anomalies. Mention CloudWatch, Budgets, tags, Athena optimization, and rightsizing.

## 4:10–5:00 — Optimization Center
Sort recommendations by priority and explain impact, effort, confidence, owner, and implementation risk.

## 5:00–5:35 — Architecture and Quality
Show the serverless architecture, data model, quality report, tests, CI, and security controls.

## 5:35–6:00 — Insights Copilot and close
Ask one sample question. Clarify that the included copilot is deterministic and that a grounded model integration is an optional production extension.
